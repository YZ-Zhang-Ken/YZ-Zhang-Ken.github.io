# 学术主页 Academic Homepage

一个**纯静态**、无需服务器、可直接部署到 **GitHub Pages** 的个人学术主页。

- 学术风排版：衬线标题 + 无衬线正文，克制的配色
- **内置可视化编辑器**：点击网页右下角齿轮 ⚙，即可在页面内直接编辑个人信息、研究方向、论文、教学、荣誉、联系方式与主题色，所见即所得
- 内容集中在 `js/data.js`，便于长期维护与版本管理
- 响应式：手机 / 平板 / 桌面均可正常浏览

---

## 目录结构

```
academic-homepage/
├── index.html        # 页面骨架
├── css/style.css     # 样式
├── js/
│   ├── data.js       # ★ 内容数据源（个人信息、论文等都在这里）
│   ├── render.js     # 把 data.js 渲染成页面
│   └── editor.js     # 可视化编辑器
├── assets/           # 放你的头像等图片
└── docs/
    └── DEPLOY_GITHUB.md   # GitHub Pages 部署图文指引
```

## 快速上手（本地预览）

本目录没有任何构建依赖，直接打开 `index.html` 即可浏览。
推荐用本地静态服务器以获得最佳体验：

```bash
cd academic-homepage
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 如何修改内容？

**方式 A —— 网页可视化编辑（推荐，适合大多数人）**
1. 打开页面，点击右下角齿轮 ⚙
2. 在"基本信息 / 关于 / 研究方向 / 论文 / 教学 / 联系方式 / 外观"等标签页中填写
3. 点底部 **"保存到本页并预览"** 即可实时看到效果
4. ⚠️ 说明：可视化编辑的成果保存在**浏览器本地**（localStorage）。换电脑或浏览器会看不到。要长期保存，请点击 **"导出 data.js"**，把下载文件里的内容粘贴覆盖到 `js/data.js` 中。

**方式 B —— 直接改 `js/data.js`（推荐给有代码习惯的人）**
所有字段都有中文注释，改完刷新即可。

## 部署到 GitHub Pages

完整图文步骤见 **`docs/DEPLOY_GITHUB.md`**。核心三步：
1. 在 GitHub 网页新建仓库（建议命名为 `你的用户名.github.io`，即"你的用户名"小写 + `.github.io`）
2. 网页上传本目录所有文件
3. 在仓库 Settings → Pages 中开启，选择分支 `main`、目录 `/root`

上线后访问 `https://你的用户名.github.io` 即可看到属于你的学术主页 🎓
